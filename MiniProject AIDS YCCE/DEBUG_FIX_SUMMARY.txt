═══════════════════════════════════════════════════════════════════════════════
ROOT CAUSE
═══════════════════════════════════════════════════════════════════════════════

Problem: Different questions produced the same or very similar responses

Example:
  Q1: "Why did cost reduce?"
  Q2: "How does travel distance affect cost?"
  → Both returned IDENTICAL generic cost reduction response ❌

Root Cause: Generic stop words (why, how, what, explain, tell, describe) 
            dominated the intent matching algorithm, preventing 
            domain-specific keywords from being properly recognized

Flow:
  Question → [Stop words checked first] → Intent matched → Response
  
  Problem: "How does travel distance affect cost?"
           ↓
           Matches "how" (generic stop word) first
           ↓
           Classifies as "why_cost_reduce" (wrong intent)
           ↓
           Returns generic cost response (wrong answer)

═══════════════════════════════════════════════════════════════════════════════
THE FIX (3 Key Changes)
═══════════════════════════════════════════════════════════════════════════════

1️⃣  STOP WORD FILTERING
   ─────────────────────
   Created a list of 13 generic stop words:
   "how", "why", "what", "explain", "tell", "describe", 
   "is", "are", "the", "a", "an", "and", "or", "but", 
   "do", "does", "did", "can", "could", "would", "should"
   
   NEW FUNCTION: removeStopwords()
   Before: "How does travel distance affect cost?"
   After:  "travel distance cost"
   
   Only domain keywords now used for intent matching! ✓


2️⃣  RESTRUCTURED INTENT KEYWORDS
   ──────────────────────────────
   OLD (Mixed):
   { name: "why_cost_reduce", 
     groups: [["why","how","reason","explain"], ["cost","saving",...]] }
   
   NEW (Domain-specific only):
   { name: "travel_cost", 
     groups: [["travel","distance","aisle","route","meter",...]] }
   { name: "why_cost_reduce", 
     groups: [["cost","saving","reduc","cheaper","lower",...]] }
   
   Result: Each intent now scores only on domain concepts! ✓


3️⃣  COMPREHENSIVE LOGGING
   ──────────────────────
   BEFORE: [ChatBot] intent="why_cost_reduce" score=2
           (No visibility into other intents)
   
   AFTER:  [ChatBot] ALL SCORES: travel_cost=1 | why_cost_reduce=1 | 
                                 labor_cost=0 | fuel_cost=0 | ...
           [ChatBot] WINNER: intent="travel_cost" score=1
           (Full transparency for debugging)
